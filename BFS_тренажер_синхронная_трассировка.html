Поиск в ширину (BFS) — пошаговая визуализация

Создание графа → запуск алгоритма → ручное выполнение каждой строки → таблица трассировки

1. Задайте граф

Вершины обозначаются буквами A, B, C, … . Для каждой вершины укажите соседей через запятую, например: C, E, F. Граф считается неориентированным: связь A–B будет отражена и у B. Порядок обхода соседей — по алфавиту.

2. Выберите стартовую вершину

До нажатия «Далее» программа не выполняет ни одного шага.
