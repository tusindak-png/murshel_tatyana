Что такое машинное обучение

Машинное обучение (Machine Learning, ML) — направление искусственного интеллекта, в котором компьютерная система обучается находить закономерности в данных и использовать их для получения результата для новых данных.

В обычной программе разработчик заранее задаёт последовательность действий. При машинном обучении система получает данные и на их основе настраивает параметры модели, выявляя закономерности.

Ключевая идея: не описывать системе все правила вручную, а позволить модели извлечь закономерности из обучающих данных.

Почему существуют разные виды машинного обучения

Не во всех задачах данные представлены одинаково. Поэтому способ обучения зависит от того, какая информация доступна модели во время обучения и каким образом она получает обратную связь.

Рассмотрим три ситуации:

  • для фотографий растений заранее указаны правильные виды;
  • есть данные о покупках, но неизвестно, какие группы покупателей существуют;
  • робот действует в среде и узнаёт качество действия по награде или штрафу.

Обучение с учителем

Обучение с учителем (supervised learning) — вид машинного обучения, при котором модель обучается на данных, для которых заранее известны правильные ответы.

Такие данные называются размеченными данными.

Основной признак: для обучающих примеров известен правильный результат.

Классификация

Классификация — определение категории, к которой относится новый объект.

Примеры: жанр музыки, вид растения, наличие дефекта детали, категория обращения пользователя.

Регрессия

Регрессия — прогноз числового значения. Например, стоимости автомобиля, расхода электроэнергии или времени доставки.

Обучение без учителя

Обучение без учителя (unsupervised learning) — вид машинного обучения, при котором модель работает с данными, для которых заранее не указаны правильные ответы.

Такие данные называются неразмеченными.

Модель самостоятельно ищет сходство, группы и другие закономерности.

Кластеризация

Кластеризация — объединение объектов в группы на основании их сходства.

Основной признак: готовых классов нет — модель должна найти группы самостоятельно.

Обучение с подкреплением

Обучение с подкреплением (reinforcement learning) — вид машинного обучения, при котором система обучается, взаимодействуя со средой и получая за свои действия награды или штрафы.

Основные понятия

  • агент — система, принимающая решения;
  • среда — пространство, в котором действует агент;
  • действие — решение агента;
  • награда — сигнал о качестве действия.
Главный вопрос: какое действие следует выполнить, чтобы получить наиболее выгодный результат?

Как определить вид машинного обучения

Не ориентируйтесь только на отдельные слова: «прогноз», «робот», «группа». Анализируйте условия обучения модели.

1. Есть ли заранее известные правильные ответы?
Да → обучение с учителем.
2. Правильных ответов нет, но нужно найти группы или структуру?
Да → обучение без учителя.
3. Система действует в среде и получает награды или штрафы?
Да → обучение с подкреплением.

Интерактивный тренажёр

Кейс 1. Для изображений деталей заранее указано «исправна» или «дефект».
Кейс 2. Сервис самостоятельно объединяет слушателей со схожими музыкальными интересами.
Кейс 3. Игровой персонаж получает баллы за полезные действия и штрафы за ошибки.
8

Как правильно обосновывать ответ

Недостаточно только назвать вид обучения. Нужно указать признак условия задачи, по которому сделан выбор.

Формула ответа:
«Используется __________, потому что __________».
Пример 1. Система определяет «исправно / неисправно»

Ответ: обучение с учителем, потому что для обучающих примеров заранее известны правильные классы.

Пример 2. Компания хочет найти группы клиентов

Ответ: обучение без учителя, потому что классы заранее не заданы, а модель должна самостоятельно обнаружить группы похожих объектов.

Пример 3. Дрон получает награду за безопасную посадку

Ответ: обучение с подкреплением, потому что агент взаимодействует со средой и получает награды или штрафы.

Главное по теме

Есть правильные ответы?
→ С учителем
Нет ответов, но нужно найти структуру?
→ Без учителя
Есть действия, среда, награды и штрафы?
→ С подкреплением

Запомните

  • С учителем: «Есть правильные ответы — научись их предсказывать».
  • Без учителя: «Правильных ответов нет — найди структуру самостоятельно».
  • С подкреплением: «Действуй, получай обратную связь и улучшай стратегию».
