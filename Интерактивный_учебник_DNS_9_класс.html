1. Зачем нужна DNS?

Каждое устройство в сети Интернет использует IP-адрес. Компьютерам удобно работать с числовыми адресами, но человеку проще запоминать понятные символьные имена сайтов. Поэтому в Интернете используется DNS — система, которая связывает доменные имена с IP-адресами.

Определение. DNS (Domain Name System) — доменная система имён, обеспечивающая сопоставление доменных имён и IP-адресов.

DNS позволяет:

  • определять IP-адрес по доменному имени;
  • сопоставлять IP-адрес с соответствующим ему именем;
  • находить сетевые ресурсы по понятным человеку именам.
Аналогия. DNS часто называют «телефонной книгой Интернета»: пользователь знает имя ресурса, а система помогает определить его числовой адрес.
Визуализация: «имя ↔ адрес»
www.example.kz ⇄ IP-адрес

2. Что такое доменное имя?

Доменное имя — символьный адрес интернет-ресурса, состоящий из частей, разделённых точками.

Пример: www.qqq.microsoft.ru

Доменное имя имеет иерархическую структуру. При анализе уровней домена удобно двигаться справа налево: от более общего уровня к более конкретному.

Структура примера: . → ru → microsoft → qqq → www

Корневой домен находится на вершине иерархии. Далее располагаются домены верхнего уровня, затем домены второго и последующих уровней, а слева может находиться имя конкретного узла или сервера.

3. Домены верхнего уровня

Домены верхнего уровня располагаются непосредственно под корневым доменом. Они могут указывать на государство или относиться к доменным зонам общего назначения.

4. Как DNS преобразует имя в IP-адрес?

Когда пользователь вводит адрес сайта, компьютеру необходимо узнать IP-адрес соответствующего сервера. DNS обеспечивает это преобразование.

  1. Пользователь вводит доменное имя. В адресной строке браузера указывается понятное имя сайта.
  2. Формируется DNS-запрос. Компьютер запрашивает информацию о том, какой IP-адрес соответствует указанному имени.
  3. DNS определяет соответствие. Система находит нужную запись и возвращает IP-адрес.
  4. Компьютер обращается к серверу. Полученный IP-адрес используется для дальнейшего сетевого взаимодействия.

5. Почему DNS имеет древовидную структуру?

Интернет содержит огромное количество ресурсов. Иерархическая организация позволяет упорядочить доменные имена и последовательно уточнять адрес ресурса.

6. Как анализировать доменное имя?

Рассмотрим условный адрес: www.school.edu.kz

Двигаемся справа налево: kz → edu → school → www

  • kz — домен верхнего уровня;
  • edu — следующий уровень доменной иерархии;
  • school — более конкретный домен;
  • www — конкретный узел или ресурс.
Главный принцип: при декомпозиции доменного имени нужно определить каждую часть и её положение в иерархии.

8. Практическое наблюдение DNS-преобразования

Увидеть результат преобразования доменного имени в IP-адрес можно с помощью сетевых команд. В учебной практике для этого используют, например, команду ping.

Пример задания. Откройте командную строку, выполните команду ping для выбранного сайта и определите, какой IP-адрес был получен. Сопоставьте доменное имя и IP-адрес.
Имитация командной строки
C:\Users\Student> ping

Это учебная имитация: реальный IP-адрес следует определять в командной строке вашего компьютера.

9. Почему DNS важна?

DNS делает Интернет удобным для человека. Пользователь работает с понятными именами сайтов, а система автоматически определяет числовые адреса, необходимые для передачи данных.

Без DNS при обращении к ресурсам пришлось бы использовать числовые IP-адреса напрямую.

Запомните. DNS связывает два представления адреса одного и того же сетевого ресурса: доменное имя ↔ IP-адрес.

10. Главное по теме

  • DNS — доменная система имён, сопоставляющая доменные имена и IP-адреса.
  • Доменное имя состоит из частей, разделённых точками.
  • Структура DNS иерархическая; уровни домена анализируют справа налево.
  • Корневой домен находится на вершине иерархии, ниже располагаются домены верхнего и последующих уровней.
  • При обращении к сайту выполняется цепочка: доменное имя → DNS-запрос → IP-адрес → обращение к серверу.
  • DNS позволяет использовать понятные человеку имена вместо запоминания числовых IP-адресов.
