Создаём справочник контактов

В школьном клубе нужен удобный справочник. Сегодня ты подготовишь данные для сохранения: выберешь типы, очистишь имя и приведёшь телефон к единому виду.

Введено пользователем

Имя: « Алия »
Телефон: «+7 700 123-45-67»

Нужно сохранить

Имя: «Алия»
Телефон: «+77001234567»

Подумай перед началом

  1. Телефон состоит из цифр. Значит ли это, что его нужно хранить числом?
  2. Почему программа не разрешает заменить первую букву командой name[0] = "О"?
  3. Как удалить лишние пробелы, сохранив имя?
Сегодня ты научишься:
  • выбирать тип данных по его назначению;
  • различать изменение объекта и присваивание нового значения;
  • использовать индексы, срезы и методы строк;
  • проверять программу на разных входных данных.

Для практики используй вымышленные контакты из учебника. Ответственное обращение с персональными данными — часть цифровой грамотности.

ТЕОРИЯ · ЧАСТЬ 1

Тип данных: значение и действия

Тип данных определяет, какие значения может принимать объект и какие операции с ним можно выполнять. Например, число можно умножить для расчёта, а в строке — найти символ или получить фрагмент.

ТипДля чего нуженПример
intЦелые числаage = 17
floatЧисла с дробной частьюrating = 4.5
boolЛогические значения: истина или ложьis_member = True
strТекстname = "Алия"
listИзменяемая последовательностьnames = ["Алия", "Данияр"]
tupleНеизменяемая последовательностьnames = ("Алия", "Данияр")
dictПары «ключ — значение»contact = {"имя": "Алия"}
setУникальные элементыclubs = {"дизайн", "робототехника"}

Сегодня подробнее изучаем str. Список и кортеж помогут сравнить изменяемые и неизменяемые объекты. Остальные структуры разберём на следующих уроках.

Как узнать тип?

Вызови встроенную функцию type().

phone = "+77001234567"
print(type(phone))
Результат: <class 'str'>

Почему телефон — строка?

Телефон нужен для связи и поиска контакта. Арифметические действия с ним не имеют смысла. Строка сохраняет знак + и начальные нули. Так же удобно хранить коды вроде "007".

Ввод и преобразование типов

input() всегда возвращает строку. Для вычислений введённый текст нужно преобразовать.

age = int(input("Введите возраст: "))
rating = float(input("Введите рейтинг: "))
phone = input("Введите телефон: ")
ВыражениеРезультат
int("17")17
float("4.5")4.5
str(17)"17"
Не любой текст можно преобразовать в число. Например, int("Алия") вызовет ValueError. Для дробного числа в примере ввода используется точка.
ТЕОРИЯ · ЧАСТЬ 2

Можно ли изменить объект?

Изменяемый объект можно изменить после создания. Неизменяемый объект нельзя изменить после создания.

Неизменяемые

int · float · bool · str · tuple

Например, заменить символ внутри существующей строки нельзя.

Изменяемые

list · dict · set

Например, элемент существующего списка можно заменить.

Строка: заменить символ по индексу нельзя

name = "Алия"
name[0] = "О"
Ошибка TypeError: строка не поддерживает замену символа по индексу.

Присвоить другое значение переменной можно

name = "Алия"
name = "Олия"
print(name)
Результат: Олия

Строка "Алия" не изменилась. Теперь имя переменной name связано с другим строковым объектом.

Различай два действия: изменить существующий объект и связать переменную с другим объектом. Неизменяемость строки не запрещает новое присваивание переменной.

Список: заменить элемент можно

names = ["Алия", "Данияр"]
names[0] = "Олия"
print(names)
Результат: ['Олия', 'Данияр']

Изменён элемент того же списка.

Кортеж: заменить элемент нельзя

names = ("Алия", "Данияр")
names[0] = "Олия"
Ошибка TypeError: кортеж не поддерживает замену элемента.
Уточнение о кортежах

Кортеж хранит ссылки на объекты. Заменить его элемент нельзя, но вложенный изменяемый объект, например список, может изменяться. Этот случай подробнее рассмотрим на следующем уроке.

Два имени могут обозначать один список

Команда b = a не создаёт независимую копию списка. Оба имени связываются с одним объектом. Если изменить этот список через b, изменение будет видно и через a.

ТЕОРИЯ · ЧАСТЬ 3

Строка: индексы, срезы и методы

Индексы начинаются с нуля

Индекс — позиция символа. Отрицательные индексы позволяют отсчитывать символы с конца.

0А−4
1л−3
2и−2
3я−1
При name = "Алия"РезультатЗначение
name[0]"А"Первый символ
name[-1]"я"Последний символ
name[0:2]"Ал"Символы с индексами 0 и 1
name[:2]"Ал"Первые два символа
name[2:]"ия"От индекса 2 до конца
name[-2:]"ия"Последние два символа
Срез: строка[начало:конец]. Правая граница не включается. Индексы и срезы читают данные, не изменяя строку.

Методы строк

Метод вызывается через объект: объект.метод(). Рассмотрим три полезных метода.

МетодДействиеПример
strip()Удаляет пробельные символы по краям" Алия ".strip() → "Алия"
lower()Переводит буквы в нижний регистр"АЛИЯ".lower() → "алия"
replace()Заменяет указанные фрагменты"123-45".replace("-", "") → "12345"

strip() не удаляет пробелы внутри текста. В replace("-", "") дефис заменяется пустой строкой — то есть удаляется.

Сохрани результат метода

name = "  Алия  "
clean_name = name.strip()

print(len(name))
print(len(clean_name))
Результат:
8
4

Метод вернул строку без пробелов. Исходная строка не изменилась. Чтобы дальше использовать результат под прежним именем, выполни присваивание:

name = name.strip()

Удаление пробелов и дефисов из телефона

phone = "+7 700 123-45-67"
phone = phone.replace(" ", "")
phone = phone.replace("-", "")
print(phone)
Результат: +77001234567

Длина строки и логический результат

len() — встроенная функция. Она возвращает количество символов. Знак + тоже учитывается.

phone = "+77001234567"
length_ok = len(phone) == 12
print(len(phone))
print(length_ok)
Результат:
12
True

= выполняет присваивание, а == сравнивает значения. Результат сравнения имеет тип bool.

Длина — только одна проверка формата. Она не доказывает, что остальные символы являются цифрами или что телефон существует.
Частые ошибки
  • name.strip() без присваивания: результат не сохранён в переменной.
  • name[0] при пустой строке: возникнет IndexError.
  • Ожидание, что name[0:2] включит символ с индексом 2: правая граница исключается.
  • Преобразование телефона в число: теряются особенности текстового идентификатора.

Что изменилось?

Для каждого фрагмента сначала предскажите результат, затем запустите код в Python. Объясните, изменился ли исходный объект. Поменяйтесь ролями: один прогнозирует, другой запускает и сверяет.

А. Обработка строки

name = "  Алия  "
clean_name = name.strip()

print(len(name))
print(len(clean_name))

Б. Присваивание строке

name = "Алия"
name = name.replace("А", "О")
print(name)

В. Два имени одного списка

names = ["Алия", "Данияр"]
other_names = names
other_names[0] = "Олия"

print(names)
print(other_names)
Критерий: объясняю поведение изменяемых и неизменяемых объектов.
  • Объясняю, сохраняется ли исходная строка после strip().
  • Различаю результат метода и новое присваивание.
  • Объясняю, почему изменение видно через оба имени списка.

Подготовь контакт к сохранению

Пользователь вводит имя и телефон. Напиши программу, которая подготовит контакт к сохранению в справочнике.

  1. Запроси имя и телефон.
  2. Удали пробелы по краям имени.
  3. Создай вариант имени в нижнем регистре для будущего поиска.
  4. Удали пробелы и дефисы из телефона.
  5. Выведи очищенное имя, его первую букву и имя для поиска.
  6. Выведи очищенный телефон и его последние четыре символа.
  7. Выведи результат проверки: равна ли длина очищенного телефона 12?
Условия задания: имя после очистки непустое; телефон после очистки содержит не менее четырёх символов. Используй вымышленные данные из таблицы.

name = input("Введите имя: ")
phone = input("Введите телефон: ")

  • Нужны две замены: пробела на пустую строку и дефиса на пустую строку.
  • Первый символ имеет индекс 0.
  • Срез последних четырёх символов начинается с индекса −4.
  • Для сравнения длины с 12 используй ==.
